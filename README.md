# SyntaxWear | Tênis e Sneakers Online 👟

A **SyntaxWear** é uma plataforma de e-commerce moderna e elegante, especializada na venda de tênis e sneakers. O projeto foca em uma experiência de usuário fluida, com um design responsivo e componentes bem estruturados, ideal para quem busca estilo e conforto em cada passo.

## 🚀 Sobre o Projeto

Este repositório contém o front-end de uma landing page de alta conversão, desenvolvida com foco em performance e manutenibilidade. O design utiliza uma paleta de cores moderna, com destaque para tons de roxo e branco, transmitindo uma identidade tecnológica e urbana.

### ✨ Funcionalidades

- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- **Navegação Intuitiva:** Menu organizado por categorias (Masculino, Feminino, Outlet).
- **Seção Hero de Impacto:** Chamada para ação clara com botões de compra e visualização de modelos.
- **Categorização Visual:** Cards interativos para diferentes estilos (Casual, Esportivo, Moderno, Futurista).
- **Grade de Produtos:** Layout otimizado para exibição de destaques e novos lançamentos.
- **Newsletter:** Área dedicada para captura de leads e fidelização de clientes.
- **Rodapé Completo:** Links rápidos, redes sociais e informações institucionais.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento front-end moderno:

- **HTML5:** Estrutura semântica para melhor SEO e acessibilidade.
- **CSS3:** Estilização avançada com o uso de:
  - **Flexbox & CSS Grid:** Para layouts complexos e responsivos.
  - **Variáveis CSS:** Facilita a manutenção e padronização de cores e fontes.
  - **Arquitetura de Componentes:** Estilos divididos por componentes para melhor organização.
- **SVG:** Ícones e logos em alta qualidade e baixo peso.
- **Google Fonts:** Tipografia selecionada (Família Ubuntu) para leitura agradável.

## 🔧 Como Executar o Projeto

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/luanfelipes7/ecommerce-syntaxwear
   ```

2. **Abrir o projeto:**
   Navegue até a pasta do projeto e abra o arquivo `index.html` em seu navegador de preferência.

   *Dica: Você pode usar a extensão "Live Server" no VS Code para visualizar as alterações em tempo real.*
